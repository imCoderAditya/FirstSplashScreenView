## 1.0.0

- 🚀 **Flagship Major Release**: Transformed into the #1 modern Splash Screen package for Flutter.
- ✨ **100+ Splash Templates**: Added comprehensive `SplashTemplate` enum supporting 100+ domain-tailored templates (Apple, Liquid Glass, Cyberpunk, Material You, AI, Space, Quantum, Crypto, Finance, Healthcare, Gaming, Luxury, etc.).
- 🧊 **Liquid Glass (iOS 26 Style)**: Introduced frosted glassmorphism with dynamic ambient lighting.
- 🎆 **GPU Particle Engine**: Added built-in particle canvas (Fireflies, Stars, Rain, Snow, Sparkles, Bubbles, Leaves).
- 🔄 **Advanced Animations**: Added Logo animations (Scale, Fade, Bounce, Flip, 3D Rotation, Pulse) and Text animations (Typewriter, Slide, Fade).
- ⏳ **Async Startup Checks**: Added support for Firebase initialization, storage, and API loading tasks.
- 🛡️ **100% Backward Compatible**: Preserved legacy `SplashScreen()` and `SplashScreen.gradient()` constructors with zero breaking changes.
- 📱 **Showcase Explorer App**: Added 100+ Templates Explorer UI with search bar and live preview.
